# PackCheck

PackCheck is a software solution for checking packaged commodities for Legal Metrology compliance.

## SIH 2026

- Problem Statement: SIH26034
- Team: PackCheck
- Hackathon: Smart India Hackathon 2026

## Project Overview

PackCheck aims to help users identify and verify mandatory declarations printed on packaged commodities using image processing, OCR, and rule-based compliance checks.
